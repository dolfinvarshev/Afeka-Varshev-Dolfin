CNN Visualization - Full Network (Input → Output)

The canvas below shows the actual trained CNN from input to output.
Conv layers: each 3×3 filter is drawn as a labeled grid - the number inside every cell is the exact learned filter coefficient (blue = positive, red = negative).
Dense layers: all connection lines are drawn with their exact weight values (unique per neuron pair).
Feature maps fill in with real activation values layer by layer when you click Test.

How It Works

  1. Upload any image - any size is accepted. The browser draws it onto a hidden 8×8 canvas to get 64 grayscale pixel values.
  2. Layer 1 - Conv2D-1 (4 filters, 3×3, same padding, ReLU): Each filter slides across the 8×8 image computing dot products at every position. The 9 values inside each kernel grid are the learned filter coefficients (shared across all positions). Output: 4 feature maps of 8×8. Total: 36 learned coefficients.
  3. Layer 2 - MaxPool-1 (2×2): No learned weights - picks the maximum of each 2×2 window, halving spatial size. Output: 4 maps of 4×4 = 64 values.
  4. Layer 3 - Conv2D-2 (4 filters, 3×3, 4 input channels, same padding, ReLU): Each output filter learns a separate 3×3 kernel per input channel → 4×9 = 36 coefficients per filter, 144 total. Output: 4 maps of 4×4.
  5. Layer 4 - MaxPool-2 (2×2) + Flatten: No learned weights. MaxPool halves again → 4 maps of 2×2 = 16 values. Flatten reshapes [4×2×2] → [16] - identical data, 1D vector format.
  6. Layer 5 - Dense-1 (8 neurons, ReLU): Each neuron is fully connected to all 16 flattened values. 128 unique learned weights + 8 biases.
  7. Layer 6 - Output (3 neurons, Softmax): Triangle, Heart, Square. All 24 connections to Dense-1 are drawn with their exact weight values. Softmax converts 3 scores to probabilities summing to 100%.
  8. Result: The neuron with the highest probability glows gold.

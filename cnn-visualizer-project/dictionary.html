ML Basics
Artificial Intelligence (AI)
The ability of a machine to perform tasks that require human-like intelligence - recognising images, understanding language, making decisions.
ML Basics
Machine Learning (ML)
A branch of AI where algorithms learn patterns automatically from data. Instead of explicit rules, the model improves through experience on examples.
ML Basics
Deep Learning
A sub-field of machine learning that uses neural networks with many layers. Deep learning achieves state-of-the-art results in image recognition, speech, and text.
ML Basics
Supervised Learning
Training where every example has a known label (e.g., "Triangle"). The model learns to map inputs to correct labels by minimising the difference between its predictions and the true labels.
ML Basics
Classification
The task of assigning an input to one of several discrete categories (classes). This project classifies images as Triangle, Heart, or Square.
ML Basics
Dataset
A collection of labelled examples used to train or evaluate a model. In this project the dataset contains images of triangles, hearts, and squares generated in Google Colab.
ML Basics
Training Set
The portion of the dataset used to adjust the model's weights. The model sees these examples during training and updates weights to reduce loss.
ML Basics
Test Set
The portion of the dataset withheld during training. It is used only to evaluate how well the final model generalises to unseen data.
ML Basics
Class / Label
A category that an example belongs to. In this project the three classes are Triangle, Heart, and Square. Each training image has exactly one label.
ML Basics
Feature
A measurable property of the input used by the model. In this CNN, features are not hand-crafted - the convolutional layers automatically learn which pixel patterns (edges, curves, fills) are useful for distinguishing Triangle, Heart, and Square.
ML Basics
Feature Extraction
Learning useful representations from raw data. In this project the CNN learns its own features: Conv2D-1 detects basic patterns in the 8x8 image; Conv2D-2 combines them into higher-level features, all automatically through training.
Neural Network
Neural Network
A computational model inspired by the brain. Layers of artificial neurons are connected by weighted links. Signals flow from input to output through those connections during the forward pass.
Neural Network
CNN (Convolutional Neural Network)
A neural network designed for images. It uses convolutional layers to detect local features (edges, corners, textures) followed by pooling and dense layers for classification.
Neural Network
Neuron
The basic computing unit. A neuron receives inputs, multiplies each by a weight, adds a bias, and applies an activation function: output = activation(sum of wi*xi + b).
Neural Network
Layer
A group of neurons that operate at the same stage of processing. This project has 6 layers: Input (64 neurons), Conv2D-1 (256), MaxPool-1 (64), Conv2D-2 + MaxPool-2 (16), Dense-1 (8), Output (3).
Neural Network
Input Layer
The first layer. It receives the raw data. In this project any uploaded image is resized to 8x8 pixels and normalised to [0,1], giving 64 pixel values that feed into the first convolutional layer.
Neural Network
Hidden Layer
One or more intermediate layers between input and output. This project has multiple hidden layers: two Conv2D layers with ReLU that detect shape patterns, two MaxPool layers that compress them, and one Dense layer with 8 neurons and ReLU.
Neural Network
Output Layer
The final layer that produces the prediction. Here it has 3 neurons, one per class (Triangle, Heart, Square). Softmax converts their raw scores into probabilities.
Neural Network
Dense Layer (Fully Connected)
A layer where every neuron is connected to every neuron in the previous layer. Both the hidden layer and the output layer in this project are dense layers.
Neural Network
Weight
A learnable parameter that scales the connection between two neurons. Weights are shown on the connection lines in the canvas visualisation - blue for positive, red for negative.
Neural Network
Bias
A learnable constant added to the weighted sum before the activation function: z = sum(wi*xi) + b. It shifts the neuron's output up or down independently of the input.
CNN
Convolution
A mathematical operation where a small filter slides over the image and computes a dot product at each position. The result is a feature map highlighting where a pattern appears.
CNN
Filter (Kernel)
A small weight matrix (e.g., 3x3) used in a convolutional layer. Each filter learns to detect a specific feature: edges, corners, curves. The output of applying a filter is a feature map.
CNN
Feature Map
The output produced by applying a filter to the input (or a previous layer). Each element indicates how strongly the filter's pattern was detected at that location.
CNN
Pooling
A down-sampling operation that reduces the spatial dimensions of a feature map. It makes the network more efficient and less sensitive to small translations of the object.
CNN
Max Pooling
The most common pooling method. The feature map is divided into non-overlapping windows; only the maximum value in each window is kept, discarding the rest.
CNN
Stride
How many pixels the filter moves at each step during convolution. A stride of 1 slides one pixel at a time; a stride of 2 halves the output size.
CNN
Padding
Adding zeros around the border of the input before convolution. "Same" padding keeps the output the same size as the input; "valid" padding does not add zeros.
CNN
Flatten
Reshaping a multi-dimensional feature map (e.g., 4x2x2) into a 1D vector (16 values). This is required before connecting convolutional layers to dense layers.
Activation
Activation Function
A non-linear function applied to a neuron's output. Without activation functions, a multi-layer network would collapse to a single linear transformation. Examples: ReLU, Sigmoid, Softmax.
Activation
ReLU (Rectified Linear Unit)
The most popular hidden-layer activation: ReLU(x) = max(0, x). Negative values are set to zero; positive values pass through unchanged. Fast and avoids the vanishing gradient problem.
Activation
Softmax
An output-layer activation that converts raw scores into probabilities summing to 1. The class with the highest probability is the prediction.
Activation
Sigmoid
An S-shaped activation: output = 1 / (1 + e^-x). Outputs are in (0, 1). Historically popular but prone to vanishing gradients in deep networks. Often replaced by ReLU.
Training
Forward Pass
Computing the network's prediction by feeding input through each layer from input to output. The browser canvas in this project animates the forward pass step by step.
Training
Loss (Cost Function)
A number measuring how wrong the model's predictions are. During training the goal is to minimise the loss. Common loss for classification: Cross-Entropy Loss.
Training
Backpropagation
The algorithm that computes gradients of the loss with respect to every weight using the chain rule. Gradients flow backward from the output layer to the input layer.
Training
Gradient Descent
An optimisation algorithm that updates weights by moving in the direction of the steepest loss decrease: w = w - learning_rate * gradient.
Training
Learning Rate
A hyper-parameter controlling the size of each weight update step. Too large means unstable training; too small means very slow convergence. This project uses the Adam optimiser with a learning rate of 0.001.
Training
Epoch
One complete pass through the entire training dataset. This project trains for up to 200 epochs with early stopping - training halts automatically when validation accuracy stops improving.
Training
Batch / Mini-Batch
A subset of training examples processed together before updating weights. Mini-batch gradient descent is a compromise between using the full dataset (stable, slow) and single examples (fast, noisy).
Training
Accuracy
Fraction of predictions that are correct: correct predictions divided by total predictions. Accuracy is reported on the test set after training to give an unbiased performance estimate.
Training
Overfitting
When a model memorises the training data, including its noise, and performs poorly on new examples. Signs: very low training loss but high test loss. Prevented by smaller models or regularisation.
Training
Underfitting
When a model is too simple to capture the patterns in the data. Both training and test losses remain high. Fixed by using a larger or more complex model.
Training
Generalisation
The ability of a trained model to perform well on new, unseen data. A model that generalises well has learned the true underlying patterns rather than memorising training examples.
Image
Pixel
The smallest unit of a digital image. Each pixel stores one colour value (R, G, B). In this project pixels are converted to grayscale: white background = 1.0, dark shape = 0.0. The 8x8 grid gives 64 input values.
Image
Grayscale
Representing an image with a single brightness channel instead of separate R, G, B channels. In this project: white background = 1.0, dark shape = 0.0. Grayscale reduces data size and suffices for shape classification.
Image
Normalisation (Images)
Scaling pixel values to a standard range (0 to 1) before feeding them into a model. Helps gradient descent converge faster and prevents one feature from dominating.
Image
Data Augmentation
Artificially expanding the training set by applying transformations: rotation, flipping, scaling, adding noise. Reduces overfitting and makes the model more robust to variations.
Deployment
Model Inference
Using a trained model to make predictions on new data as opposed to training. In this project, inference is the forward pass run entirely in the browser using weights stored in localStorage via JSON.stringify and JSON.parse.
Deployment
Model Export
Saving trained weights so they can be used later or in another environment. The Colab script exports weights rounded to 4 decimal places as a compact JSON object.
Deployment
Hyper-parameter
A configuration value set before training that is not learned from data. Examples: learning rate, number of layers, number of neurons, number of epochs.
Deployment
Parameter
A value that the model learns during training, specifically the weights and biases. Parameters are updated by gradient descent to minimise the loss function.
Deployment
Confidence / Probability
The softmax output for each class, representing how certain the model is about its prediction. A confidence of 84% for Triangle means the model assigns 84% probability to that class.
